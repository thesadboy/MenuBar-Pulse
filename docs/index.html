Features

模块化设计，无感融入 macOS

每一项监控均可独立启闭与拖拽排序，精准呈现关键指标，拒绝冗余与打扰。

实时网络流速 (Network Pulse)

内核级精准采样，告别 32 位流量溢出

通过系统底层 64 位 sysctl (NET_RT_IFLIST2) 接口直接读取网络硬件接口字节计数，避免高负载下的流量统计截断。支持上下双行紧凑微型堆叠（Stack）与左右并排（Opposed），支持自定义单色、彩色区分以及微速自动隐藏。

展示布局: 双行堆叠 / 左右并排 零堆内存分配

内建胶囊电池 (Battery Care)

像素级贴合 macOS 原生电池轮廓，电量百分比与充放电状态直观呈现。深入读取原厂设计容量与健康衰减度、循环充放电次数、实际协商功率及出厂使用时长。

健康度计算 充放电循环 出厂年龄

智能风扇转速 (Smart Fans)

自动检测并适配单风扇机型（MacBook Pro 13" / Mac mini）与双风扇机型（MacBook Pro 14"/16"）。支持双风扇独立并列展示或跟踪最高转速，无风扇机型（MacBook Air）智能休眠静音。

双风扇独立 无风扇静音识别

10 大分类硬件温度 (Thermal Matrix)

细致入微的硬件传感器探针

整合 Apple Silicon SMC 与 IOHID 内核传感器事件，划分为中央处理器、图形核心、SoC、统一内存、固态硬盘、电池电芯、供电组件、散热风道等 10 大硬件类别。浮动面板支持分类一键展开与高温阈值警示。

CPU GPU SoC 内存 SSD 固态 电池电芯 供电组件 机身掌托

安装与启动

提供开箱即用的预编译 DMG 安装包，亦可直接克隆源码本地一键编译。

方式一：下载 DMG 安装包

推荐日常使用
1
下载安装包
从 GitHub Releases 下载最新的 MenuBarPulse.dmg
2
拖入应用程序
双击打开挂载镜像，将图标拖拽至 Applications 文件夹即可
3
即刻使用
在启动台中打开 MenuBar Pulse，状态栏指标即时就位
前往 Releases 下载 DMG (v1.1.1)

方式二：源码本地编译

开发者选项
1
克隆代码仓库
git clone https://github.com/thesadboy/MenuBar-Pulse.git
2
执行一键编译脚本
cd MenuBar-Pulse/MenuBarPulse && ./build.sh
3
自动安装运行
脚本完成编译与本地代码签名，直接安装至应用程序并启动
查看 GitHub 源代码

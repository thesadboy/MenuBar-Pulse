模块化系统设计，为专业 Mac 用户打造

每个模块均支持独立启用、独立排序与专属定制，完全融入 macOS 人机交互指南。

实时网络脉冲 (Network Pulse)

基于 64 位内核路由接口 sysctl (NET_RT_IFLIST2) 驱动，彻底解决 32 位溢出 Bug。支持双行微型堆叠（Stack）与左右并排（Opposed），提供 180° 数学对称微型箭头与视网膜冷暖色彩光渗光学补偿。

排版样式: 双行堆叠 / 并列 零内存堆分配

内建胶囊电池 (Battery Care)

1:1 像素复刻 macOS 原生电池框体与端子，电量颜色无缝贴合外框。实时监测电池设计容量、真实健康寿命百分比、循环计数与出厂年龄推算。

智能双风扇独立监控

自适应单风扇（MacBook Pro 13"）与双风扇（MacBook Pro 14"/16"）机型。支持左右风扇并列展示、独立最高速或单侧锁定，支持 M 系列无风扇机型静音识别。

10 大分类全维度温度透视

整合 Apple Silicon SMC 与 IOHID 内核事件探针，划分为中央处理器、图形处理器、SoC芯片、统一内存、固态硬盘、电池电芯、散热风道等 10 大硬件类别，支持单项折叠展开与峰值告警。

安装指南

两种方式，三步完成，即刻启动你的 Mac 监控中心。

推荐

方式一：下载 DMG 安装包

1
下载安装包
前往 GitHub Releases 下载最新的 MenuBarPulse.dmg
2
拖拽安装
双击打开 DMG 挂载镜像，将 MenuBarPulse.app 拖入 Applications 文件夹
3
启动应用
在启动台中打开 MenuBar Pulse，状态栏图标即时呈现
